To navigate: Use the menu on the left to access the different topics.
   
Viewing descriptions: You will need Acrobat Reader in order to view the different Zelio Logic Descriptions (Catalogue, Installation Description, User Guide, Library and Tutorial). Choose the "Utilities" option in the Start menu to install this software program.
   
Viewing examples:

The "Zelio Soft for PC (version 2.0)" software program must already be installed on your computer. Open the file you wish to view by simply clicking on the link.
Note : with certain Web browsers, the file may not automatically open. In that case, save the file locally before opening.
