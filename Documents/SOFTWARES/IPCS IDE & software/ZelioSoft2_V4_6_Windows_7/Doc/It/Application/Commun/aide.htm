Visualizzazione delle descrizioni: per visualizzare le Descrizioni di Zelio Logic (Catalogo, Descrizione dell'installazione, Manuale d'uso, Libreria e Autoformazione) è necessario disporre dell'applicazione Acrobat Reader. Per installare questo programma, selezionare l'opzione "Utility" dal menu di avvio.
