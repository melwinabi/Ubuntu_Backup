Para navegar: utilize o menu do lado esquerdo para aceder às diversas secções.
   
Visualização das descrições: é necessário ter o Acrobat Reader para visualizar as diversas descrições do Zelio Logic (Catálogo, Descrição de instalação, Guia de exploração, biblioteca e formação automática). Para instalar este software, utilize o menu de arranque e escolha a opção "Utilitários".
   
Visualização dos exemplos:

primeiro, tem de ter o software "Zelio Soft para PC (versão 2.0)" instalado no computador. Basta clicar na hiperligação para abrir o ficheiro pretendido.
Observação : em determinadas versões de Web browsers, a abertura não é automática. Nesse caso, basta escolher a opção para guardar o ficheiro no disco e depois abri-lo.
