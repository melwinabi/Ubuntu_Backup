Para evitar cualquier consumo excesivo al encender una caldera, se realiza un aumento de potencia de los elementos de calefacción y, durante la parada, se realiza un apagado sucesivo de dichos elementos.

Se puede definir el principio de funcionamiento como lo muestra el cronograma siguiente: El botón "Marcha" (MA) permite activar el primer elemento de calefacción (S1). Tras una duración T (temporización), se activa el segundo elemento (S2). Tras la misma duración T, se activa el tercer elemento (S3) y, a continuación, el cuarto (S4), siempre una vez transcurrido el tiempo T. El botón "Paro" (AR) desactiva S1. Los tres elementos restantes se desactivan progresivamente una vez transcurrido T entre la desactivación de cada uno de ellos.
